# SheepIt Plus 前端设计说明

配套高保真稿：`design/sheepit-plus-design.html`（单文件，浏览器直接打开，顶栏可切换 9 个视图、亮/暗主题、5 种状态）。

---

## 一、设计判断（约 280 字）

老站（2013 Bootstrap + jQuery）最大的三个问题都是**压缩**：① 标签截断、进度数字压在双色条上，白字在半满的条上两边都读不清；② 六列挤进 620px，半块视口空着；③ 761 条原始日志直接铺满首屏，重要的机器状态反而被埋掉。

我的取舍是**反压缩**：进度数字移出进度条并独占一列（44 行实测 11 种轨道宽度的教训）；53 周热力图必须整宽全出血，宁可横向滚动也不缩成噪点；日志先按天/月汇总，原始记录收进一个写明条数的按钮后面。

为什么这更适合"数据密集的日常工具"：用户每天扫一眼就走，要的是"读数正确"，不是"页面好看"。所以结构做到隐形——单栏 1240px、灰阶三层、1px 发丝线、表格数字全部 tabular-nums——把唯一的暖色（品牌橙）省下来只做三件事：可点击的、当前选中的、代表"你"的。颜色稀缺了，信息才稀缺得有意义。

## 四、逐视图布局说明

统一栅格：单栏居中 max 1240px，侧 padding 24px（<620px 收 16px），页底留 72px。桌面优先 1368/1440，断点 1200 / 1000 / 860 / 760 / 620。账户与分析/上传走 820px / 680px 窄栏——表单一行一个控件。

1. **总览**：身份条（头像 56 + display 名字 + since/当前帧 meta）→ KPI 带 4 格（发布过项目则扩到 5–6 格，折叠 6→3×2→2×3 时重算内边）→ 8/4 分栏：左 216px 积分面积图、右 132px 月度柱状图（<1000px 折单列；他人页面两图**缺席而非空态**）→ 53 周热力图整宽 → 在线机器 + 我的项目最近 5 个。
2. **项目**：全站实时条（剩余帧/活跃项目/在线客户端/渲染中帧）置顶齐平——农场数据属于这里而非总览 → 工具行（搜索 + 状态分段筛选 + 计数）→ 项目表：发布者（含名单标记按钮：优先/移除，文字即状态）、CPU/GPU 徽标、内存、进度（轨道列 + 分数列）、优先级开关、三点菜单 → 分页"显示更多（100 / 44）"。
3. **排行榜**：1658 行、每页 100、自己行 `--wash` 高亮 + you 标；分页分段控件。
4. **会话页**：机器头（状态 chip——全系统唯一允许着色的状态，渲染中=橙实底近黑字，暂停=橙洗）+ 唯一橙按钮"暂停此机器" → 4 数带 → 20 项机器信息双列 facts 网格（<720px 单列；渲染密钥默认遮罩 + 显示按钮；未知字段按原始标签打印）→ 活动汇总（按天/按月分段，相对条形）→ 完整日志折叠 → 可渲染项目表（**保持站点原序，顺序即优先级**，原因进状态列）。
5. **账户设置**：820px 窄栏 + 三标签分段控件（调度与名单 / 捐赠积分 / 账户），标签记忆不写地址栏。每面板**恰一个橙提交钮**（One Commit Rule）；名单行 = 22px 头像 + 链接名 + 尾部次按钮移除；密钥行 12.5px tnum + 截断注释 + 使用中徽标；空名单保留边框写"（空）"；头像文件框用 1px 透明 input + `:focus-within` 环，不用 `display:none`。
6. **上传**：拖放区（虚线强发丝边）→ 上传进度 → 切块方案对比表（1,300 / 650 / 12,000 三档）→ 排队位置双格 → 须知。顶部明示"实验性 · 控件搬自站点 · 限制值（12,000 / 4096×2160）为实时读取"。
7. **分析等待 + 项目设置**：进度条（分数在条外）→ 完成后展开站点返回的设置表单，并明示"此步骤未重实现、未经完整验证"，提供"在经典界面中填写"出口。
8. **项目管理**：动作行（恢复=唯一橙钮，暂停/重分析/删除均次按钮）→ tiles 墙（10px 格墙直观表达 1300 切块进度）→ ACL 名单 → 删除走 `alertdialog` 二次确认。
9. **未接管页**：仅翻译层 + 左下角自带样式的"进入新界面"胶囊（底部左侧是经典站唯一空角）。

## 六、自检清单

- **对比度**：ink 对底 14.8:1（暗）/ 15.9:1（亮）；ink3 对底 ≥4.6:1（三级灰仍可读，不做"更浅更灰"）；暗橙上近黑字 7.4:1，亮深橙上白字 5.3:1——白字不上暗橙是硬约束。
- **键盘路径**：隐藏一律 opacity/1px 透明（文件框、三点钮、开关 input），焦点环 `:focus-visible` 2px 橙偏移 2px；开关焦点环落轨道；菜单 `:focus-within` 可唤出；弹窗 `alertdialog` 焦点管理；表 `aria-sort`；分段控件 `aria-pressed`；当前 nav `aria-current`。
- **中英切换**：单系统字体栈同时承载 CJK/Latin，无 webfont；文案中文优先、英文完整（站点原始字段名保留英文原文 + 中文注释）。
- **390px**：表格横滚不折卡片；热力图固定 14px 格横滚；nav 标签缩短（排行榜→排行）不隐藏；时间戳 <860px 隐、用户名 <620px 隐。
- **缩放**：90%–140% 下 KPI 带、facts 网格、热力图均按 token 栅格伸缩，无固定像素依赖。
- **体积估算**：HTML+CSS+SVG+JS 合计约 55KB，gzip 后约 14KB，460KB 预算的 3%——余量留给真实数据渲染。
- **一条声音审计**：项目表渲染态中橙色只出现在进度填充、选中徽标、you 标、主按钮——第四种用法即缺陷。

## 七、需要你拍板的 3 个问题

1. **排行榜"你"的页面定位**：1658 行翻页找自己体验差，是否在表头加"跳到我"按钮（纯前端定位，不加功能）？还是坚持不加，靠分页？
2. **上传页的"实验性"开关默认关**：开与关的文案已写好，但开关放在账户设置的哪个标签页——"调度与名单"尾部，还是单列第四个"实验"标签？
3. **会话页状态 chip 是唯一被允许着色的状态**（2026-10-04 已定例外）。项目表里"已暂停"项目目前保持中性灰——要不要也援引同一例外，还是守住"例外只此一处"？
