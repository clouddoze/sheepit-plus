## 这一轮明确不做

| 不做 | 为什么 |
|---|---|
| 换框架 / 拆服务 / 上构建链 | 发布形态锁定单文件油猴脚本 |
| 接论坛 | 独立 phpBB3、独立 cookie（拍板） |

| 外部 CDN 字体 / 旧浏览器兼容 | 未选为约束；现代 Web 策略见 `MODERN-WEB.md` |
| 为体积删「为什么」的注释 | 再压就是删防回归依据 |
