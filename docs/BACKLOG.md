## 功能候选（2026-11-22 讨论，未排期）

前提：只读站点页面、单文件、@grant none，不碰写接口与上传。

**低成本**
- 命令面板（Ctrl+K）：跳页 + 搜项目 / 用户 / 团队（数据已在 state 里）。
- 收藏 / 置顶项目：Store 存 project id，列表置顶。
- 导航补全：「更多」加 FAQ / Servers / 捐赠外链（见上文「已知缺口」）。
- 快捷键：`/` 聚焦搜索、`g o/p/r/l` 跳页、`r` 刷新。

**中等成本（对发布者价值大）**
- 完成时间预测：轮询存 {id, done, ts}，算帧/分钟，进度列给「约 X 小时」。
- 卡住告警：N 分钟 done 不变 → 标记「可能卡住」。
- 机器离线提醒：会话状态运行→离线时页面内提示。
- 导出 CSV：当前筛选结果，Blob 下载。

**暂不做**：全站搜索（无接口）、虚拟滚动（数据量小）、团队批量写操作（贴边不接管）。
